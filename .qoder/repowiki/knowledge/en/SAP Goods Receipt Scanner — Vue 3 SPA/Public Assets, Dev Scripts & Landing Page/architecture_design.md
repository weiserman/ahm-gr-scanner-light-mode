Three independent sub-trees with no cross-dependencies:
- `public/` — two standalone Service Workers registered by the app: `sw.js` is the production worker (install/activate/fetch pass-through with `clients.claim()` takeover), `mock-sw.js` intercepts `/odata/v4/catalog/*` requests and returns synthetic delivery payloads plus a minimal `$metadata` XML so the OData client validates without a real backend.
- `scripts/` — Bash tooling for the hybrid Android development loop. `watch.sh` polls local files via `stat -c %Y`, pushes deltas to `/sdcard/Documents/MyHybridMobile/www` and copies them into the app sandbox via `run-as com.example.app`, then broadcasts `ACTION_RELOAD_WEBVIEW`. `push.sh` does a one-shot full sync of root config + `src/public/dist` into the same staging area. `start.sh`/`stop.sh`/`restart.sh` drive the target package through ADB (`monkey` launch, `am force-stop`). `zip.sh` zips the repo into `zip/main.zip`, serves it on port 8080 via `darkhttpd`, and prints a terminal QR code of the download URL. `chrome.sh` opens Chrome with web security disabled at `localhost:4321` for desktop debugging.
- `docs/` — a single-page HTML site served from GitHub Pages; it derives the GitHub username/repo from `window.location.hostname`, builds an `ahm-app://deploy?package_url=...` deep link, attempts an automatic redirect, and renders a QR code (via qrcodejs CDN) as a fallback for mobile scanning.
