The root is a flat Vite project whose entry points are two HTML shells: `index.vite.html` (Vite dev/build target, imports `/src/main.js`) and `index.html` (legacy import-map fallback loading `./src/util/keyboard.js` then `./src/main.sfc.js`). `vite.config.js` centralises cross-cutting concerns shared by every child module — it rewrites the dev-server root to serve `index.vite.html`, renames the built artifact back to `dist/index.html`, detects the WSL host IP and prints a QR code so phones can reach the dev server on LAN, and exposes `host: '0.0.0.0'` plus CORS for the local proxy broker used by `util`. The app runtime is split across children (`app_shell` bootstraps Vue + router + barcode wedge input, `views` compose feature pages, `components` provides reusable UI, `util` holds the global store/OData transport/service-worker registration, `lib_vendor` ships Vue/Router/html5-qrcode as checked-in ESM files, `public_assets` hosts the SWs and GitHub Pages landing page), but all of them resolve through the single Vite graph rooted at `index.vite.html` → `src/main.js`.
