Flat directory of independent Vue 3 `<script setup>` SFCs under `src/components/`, each self-contained with its own scoped CSS. Two sub-packages follow an `index.vue` entry convention: `qrcode/generator/index.vue` renders an SVG via the local `lib/qr-code-generator` library, while `qrcode/scanner/index.vue` mounts the third-party `html5-qrcode` engine into a fixed-position overlay and bridges native Android permissions through `/api/permissions/*` fetch calls. The `dialog/` package is split across `CustomDialog.vue` (the visual overlay) and `useDialog.js`, which owns a singleton state object stored on `window.__VUE_CUSTOM_DIALOG_STATE__` and exposes `openDialog` plus `initWindowOverrides` to replace `window.alert/confirm/prompt`. All other components (`menutop`, `pinmobile`, `refreshbutton`) are pure presentational/consumer-facing SFCs with no cross-component imports — they communicate only via props, emits, or direct DOM/window APIs.
