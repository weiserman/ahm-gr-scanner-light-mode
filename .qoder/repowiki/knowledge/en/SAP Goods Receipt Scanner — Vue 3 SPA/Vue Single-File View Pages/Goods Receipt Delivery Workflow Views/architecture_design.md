Six sibling Vue 3 `<script setup>` pages under `src/views/`, each a self-contained route entry sharing a common layout shell (`MenuTop` + `.app-layout/.content-workspace`). The pages form a linear state machine driven by a global reactive store at `../../util/store.js` with a fixed cache key `store.cache.entityLists['ActiveDelivery']`; every view reads this envelope (delivery header + nested `items[]`) via computed properties that normalize both array and single-object shapes. Navigation between screens is purely router-based (`/register_delivery` → `/goods_to_scan` → `/po_items` → `/receipt_item` ↔ `/outbox_item` → `/scanned_goods`), with cross-view selection passed through `route.query.articleCode`. Scanning integrates two channels: an on-screen QR overlay (`QrCodeScanner` component) toggled via `isWebcamScannerOpen` from `../../util/barcodeScanner.js`, and a hardware laser broadcast on `window.addEventListener('zebra-hardware-scan-completed')` consumed only by the receipt-item screen. Backend calls are funneled exclusively through `EntityService` (`getDeliveriesList`, `executeDraftGoodsReceiptPipeline`) rather than direct HTTP, keeping these views as pure presenters over the shared store.
