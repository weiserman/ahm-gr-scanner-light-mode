Each subdirectory under `src/views/` is a self-contained feature page exposing a single `index.vue`; there is no shared view base class — pages are wired together at the router level (outside this scope) and communicate via the global Pinia store (`useStore`) and shared composables (`MenuTop`, `showToast`, `showLoading`). The three child modules here split by user journey: `home/config/about` form the persistent shell, `pinenter/pinsetup/register_delivery` handle onboarding/security, and `register_delivery/po_items/scanned_goods/goods_to_scan/outbox_item/receipt_item` implement the goods-receipt flow. Views never import each other directly; cross-view state flows through the store.
