Three sibling Vue single-file components, each mounted at its own route (`/enroll`, `/setup`, `/enter`) and composed of a thin layout shell plus the shared `PinMobile` keypad component from `../../components/pinmobile/PinMobile.vue`. State is not kept in props — views read/write the global store via `store` and `storeActions` imported from `../../util/store.js`, which persists OData config and `appPin`. Navigation between steps is driven by `vue-router`: after saving credentials the enroll view routes to `/setup` (no PIN yet) or `/enter` (PIN already exists); successful PIN entry goes to `/home`; a 'Forgot PIN' flow calls `storeActions.resetStore()` then pushes `/setup`. The enroll screen additionally composes `QrCodeScanner` (`../../components/qrcode/scanner/index.vue`) and toggles it through the shared `isWebcamScannerOpen` flag in `../../util/barcodeScanner.js`, accepting both legacy `{odataUrl}` payloads and the newer flat `{baseHost, poPath, grPath, ...}` payload. Each view owns only one concern: `enroll` collects/import config, `pinsetup` performs two-phase PIN creation with match validation, `pinenter` validates an existing PIN against `store.appPin`.
