Flat vendor tree under `src/lib/`, one sub-directory per dependency. Each directory holds a pre-built distribution artifact rather than source code — e.g. `vue/vue.esm-browser.prod.js`, `vue-router/*.cjs` / `*.esm-browser.js` / `*.global.prod.js` multi-format builds, `qr-code-generator/qr-code-generator-lib.{cjs,mjs}`, and `vue3-sfc-loader/vue3-sfc-loader.esm.js`. The app imports these artifacts via relative paths from `src/components/` and `src/util/sfcBootstrap.js`; `index.html` also maps the `vue` package name to the local ESM build for browser `<script type="module">` resolution. There is no bundler-side aliasing or symlink — consumers reference the files literally, so updates require replacing the checked-in artifacts manually.
