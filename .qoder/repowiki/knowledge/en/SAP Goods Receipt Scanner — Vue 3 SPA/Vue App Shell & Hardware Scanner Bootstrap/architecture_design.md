Three-file leaf entry point:
- `src/main.js` is the single JS bootstrap: creates the Vue app via `createApp(Main)`, registers `./router/index.js` as a plugin, imports `style.css`, and mounts to `#app`. A service worker registration call exists but is commented out.
- `src/Main.vue` is the root `<script setup>` component whose template only renders `<router-view>` inside a `.minimal-container`. It owns cross-cutting lifecycle for hardware scanning: on mount it programmatically injects a hidden `<input id="hardwareScanCatcher">` into `document.body`, attaches a `keydown` listener for Enter-triggered barcode processing, a capture-phase click listener to reclaim focus, and a 1-second `setInterval` (`window.zebraFocusStabilizer`) to keep focus stable across route transitions. Scanned barcodes are dispatched as a custom DOM event `zebra-hardware-scan-completed` and also drive programmatic navigation via `router.push('/receipt_item')`; the active delivery data is read from the shared `store.cache.entityLists['ActiveDelivery']` in `./util/store.js`.
- `src/style.css` defines the global CSS variable palette (`--bg-color`, `--accent-color`, etc.), resets `html/body`, and provides layout classes (`.app-layout`, `.app-header`, `.app-content`) plus mobile-friendly defaults (safe-area insets, overscroll suppression, hidden scrollbars).

Dependency direction is one-way: `main.js` → `Main.vue` → `./util/*` (barcodeScanner, store, serviceWorker); no other module imports this shell back.
