Flat feature-folder layout: one directory per route (`home`, `about`, `pinenter`, `pinsetup`, `register_delivery`, `goods_to_scan`, `scanned_goods`, `po_items`, `outbox_item`, `receipt_item`, `enroll`, `config`), each exposing a single `index.vue` SFC consumed by the router. Every page composes the shared `MenuTop` bar from `../../components/menutop/index.vue` and reads/writes state exclusively through the centralized store module at `../../util/store.js` plus its action helpers (`storeActions`). Navigation is done via `vue-router`'s `useRouter()` pushing named paths like `/register_delivery`, `/goods_to_scan`, `/enter`. Cross-cutting UI primitives (`PinMobile`, `useDialog`) are imported from sibling `components/` folders rather than being defined inline, keeping views thin presentational shells over business logic in the store layer.
