Flat collection of vendored npm packages under `src/lib/<pkg>/`, consumed directly by application code via relative imports — no internal layering. Consumers load them in two ways: (1) ESM import from a `.mjs`/`.esm-browser.prod.js` entry (`vue`, `qr-code-generator`) used by SFC components; (2) global IIFE script injected at runtime (`vue-router.global.prod.js` loaded dynamically by `src/util/sfcBootstrap.js`, which also exposes `window.Vue` for it). The SFC bootstrap (`sfcBootstrap.js`) is the only place that wires these pieces together: it calls `loadModule` from `vue3-sfc-loader` to compile `.vue` files on the fly, rewrites `from 'vue'` / `from 'vue-router'` imports to data URLs pointing at the already-loaded globals, and caches compiled modules in `customJsCache` keyed by absolute path. `index.html` declares a Vite-style `map` alias for `vue` so the loader resolves it to the local prod artifact. Empty directories (`petite-vue`, `html5-qrcode`, `vue3-sfc-loader`) are placeholders for additional vendor assets not yet wired in.
