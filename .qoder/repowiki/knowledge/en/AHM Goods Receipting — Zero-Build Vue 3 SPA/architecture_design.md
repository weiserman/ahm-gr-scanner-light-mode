The root orchestrates three layers: (1) `index.vite.html` is the Vite entry point consumed by `vite.config.js`, which registers the Vue plugin, rewrites `/` to the Vite HTML during dev, renames the build artifact back to `dist/index.html`, and auto-prints a QR code of the WSL host LAN address so phones can reach the dev server; (2) the runtime bootstrap (`app_entry_and_main`) mounts the root layout, configures Vue Router against the `views/` screens, and injects the global store and SAP OData adapter from `util`; (3) `lib_vendor/` supplies prebuilt browser bundles of Vue, vue-router, html5-qrcode and qr-code-generator so the whole stack runs without a Node build step. Production output goes to `dist/` and can be served by `serve.sh` (darkhttpd on port 4321) or `npm run serve:dist` (Python http.server on 8000).
