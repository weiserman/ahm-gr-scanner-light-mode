The module is organized as a flat set of single-responsibility ES modules that compose into three layers:

- **State layer** (`store.js`): a singleton `window.__GLOBAL_APP_STORE__` built on Vue's `reactive()` + a deep `watch` to localStorage under key `vue_sfc_template_store`. It ships a migration path from the legacy `config.odataUrl` field to the current `baseHost`/`poPath`/`grPath` triple, and exposes mutating actions (`saveODataConfig`, `resetStore`, …) so callers never touch the object directly.
- **Transport layer** (`odata.js`): the only outbound HTTP entry point. Every request is POSTed as a JSON envelope to the same-origin AHM native proxy broker at `/api/net/request`, which bypasses browser CORS. The module injects Basic Auth, enforces `$format=json`, lazily fetches and caches an X-CSRF-Token for modifying requests, replays Set-Cookie values across calls, and transparently retries once on 403 by refreshing the token.
- **Domain adapter** (`entities.js`): `EntityService` composes `odataFetch` with SAP-specific endpoint paths (from `store.config.poPath` / `grPath`) and normalizes raw payloads into the internal delivery-document shape consumed by the Vue UI. It also implements the RAP draft pipeline (create header → append `_Item` lines → invoke namespace-bound `Activate` action).
- **Runtime helpers**: `serviceWorker/serviceWorker.js` registers `/sw.js` and provides `sendWorkerMessage`/`listenForWorkerMessages`; `sw.js` toggles the mock `mock-sw.js` worker based on `store.config.useDummyData`; `barcodeScanner.js` exports shared Vue refs (`isGlobalScanningActive`, `isWebcamScannerOpen`, `isUserEditing`) used by Main.vue and scanner components; `keyboard.js` installs a Ctrl+R reload shortcut; `sfcBootstrap.js` loads Vue 3 + vue-router globals and uses `vue3-sfc-loader` to compile `Main.vue` and `src/router/index.js` at runtime without a build step.

Dependency direction is strictly one-way: `entities.js` → `odata.js` → `store.js`; helper modules are independent leaf imports. There is no cross-import between helpers.
