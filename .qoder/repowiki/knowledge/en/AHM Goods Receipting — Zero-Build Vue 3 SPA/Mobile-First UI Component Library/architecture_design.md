Each subdirectory is an independent, self-contained component with no cross-imports between siblings; consumers import them directly from `src/components/<name>/...`. Cross-cutting concerns are handled per-component rather than via a shared parent: global state (dialog) lives on a `window` key (`__VUE_CUSTOM_DIALOG_STATE__`) so non-Vue code can trigger it, hardware access (camera scanner) talks to the Android WebView through `/api/permissions/*` endpoints, and styling relies on CSS custom properties (`--surface-color`, `--accent-color`, etc.) defined elsewhere in the app. Components that need lifecycle cleanup (menu popover click-outside, keyboard listener, camera stream) register listeners in `onMounted`/`onBeforeUnmount` or `onMounted`/`onUnmounted` respectively.
